# 当前交付范围：AI延期为扩展项

日期：2026-10-27。依据：用户明确要求“先不接入AI，以后作为扩展项”。这是V4.0及场景改版方案的范围补充，优先于其中的AI必做项，原始V4.0不改写。

## 当前产品

选择或描述经营想法 → 手动选择经营方式与确认条件／主动使用演示假设 → 场景筹备与经营 → 方案比较 → 手动现实挑战与观察。

想法文本只保存原句，不自动抽取预算、成本、商品或经营类型，不宣传自然语言自动生成场景。规则提示来源于确定性计算，不称作AI分析。场景、动画、经营计算、保存和比较不需要模型Token。

普通页面移除Agent准备、分析及任务起草组件，不请求模型状态；后端AI路由统一默认关闭，返回503 AI_FEATURE_DEFERRED。旧BO_LLM_*环境变量不会自动开启扩展，用户也不能通过提交Key启用。没有新增模型费用。

已有Agent实现、兼容契约和数据保留；扩展回归测试显式选择Settings(ai_features_enabled=True)，生产启动不从环境读取这个开关。恢复AI应作为新的明确开发任务，重新处理费用控制和服务商验证。

## 下一步

当前不因增加创新性引入多人、自由装修、支付、虚拟货币或大型游戏系统。赛事是否要求AI或指定平台仍需完整规则核实，不根据其他作品的表面表现推断。
