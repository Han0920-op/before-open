# 阶段4：ScenarioAgent 与用户模型接入

日期：2026-10-25。状态：**核心代码、离线/隔离验收已完成；真实服务商联调尚未完成**，不能据此宣称真实模型准确率或所有服务商可用。

## 本轮需求与结果

用户要求参考 V4.0 推进阶段4，并明确提出由前端选择接入模型。现已增加顶部“模型接入”：DeepSeek、OpenAI、通义千问及后端白名单内的候选模型，用户填写自己的 Key、确认可能费用后，主动调用 Agent 创建和分析场景。

- **单个 ScenarioAgent**：LangChain 结构化模型输出、LangGraph 状态机与恢复；没有多 Agent 对话、任意 shell/SQL/URL 工具。
- **事实与草稿**：数值必须有原句连续证据、唯一数字及单位对应，Python Decimal 校验金额转换；模型不能声明任意 source。未知成本、销量和“半天”等未明确分钟数保持未知，最多追问3条。
- **保护已有事实**：澄清只补空值；已有确认版本的值优先保留，原句重新抽取不能覆盖。已有方案作为父版本；更换业务类型要求手动确认，不悄悄重建。
- **人工确认**：草稿在 LangGraph interrupt 停下，用户明确确认后才保存版本并运行模型规划。建议改备货仍需再次确认，创建独立子版，原版不变。
- **真实工具**：模型选择2～3个上下文适用的白名单工具，实际执行 validate_scene、零售/服务计算、预算、需求情景或版本比较；风险卡由确定性结果生成，最多3张。工具请求、版本、摘要、状态和持续时间都真实记录。
- **任务草稿**：模型起草低成本现实挑战，运行结构验证并记录工具轨迹；页面展示为可编辑草稿，保存仍需用户操作，不创建虚构观察。
- **恢复、事务与限额**：checkpoint 与业务事实分表、同事务提交；新应用实例可恢复人工确认中断。失败时版本/模拟/风险/状态回滚，执行轨迹标明 rolled_back，清除失效输出和临时版本引用。每用户交互段最多8节点/6调度，模型操作最多2次尝试。
- **模型连接隐私**：Key 只在当前服务进程内按匿名会话暂存，30分钟有效，不写浏览器持久存储、数据库、checkpoint、幂等记录或工具日志。断开/过期/重启后需重连。公网要求 HTTPS，固定服务地址，不接受用户任意 URL。
- **诚实失败**：未接入时是 failed/LLM_UNAVAILABLE、模型调用数为0；不以规则假装 LLM。密钥、访问、额度、超时、非法输出、模型切换、限额有安全错误提示；手动沙盒不依赖 AI。

## 已诊断并修正

- 初始迁移必须先为旧 AgentRun.thread_id 建唯一索引，再创建 checkpoint 外键；修正后升级成功。SQLite batch 重建显式保留原工具时长 CHECK 约束，未丢弃校验。
- LangGraph 使用显式 TypedDict 状态与 RunnableLambda，独立 checkpointer 在节点与框架写入间串行保护共享 Session；不把聊天状态当作业务事实表。
- 只有已完成实际结构化请求后才标记连接曾调用成功；刚填写 Key 不触发验证或费用。
- 工具失败后临时版本不留下，已执行但回滚的工具不冒充成功。任务草稿工具的持续时间包含实际模型生成与校验。
- 对已确认方案生成新草稿时，不再从原句覆盖后来手动确认的预算、库存等值。

## 真实联调所需外部条件

当前没有用户提供的有效模型 Key，也没有产生真实模型费用。对模型地址的无凭据只读诊断被代理拒绝，明确收到 `Tunnel connection failed: 403 Forbidden`。这不是“Key无效”的证据。

已将 api.deepseek.com、api.openai.com、dashscope.aliyuncs.com 加入云环境网络草稿，同时保存阶段4的安装/启动指引。工具返回 saved、requires_publish=true；**草稿未应用、环境未发布**。需在环境设置审阅、保存并发布后再验证网络。

真实使用时，在网页选择自己的服务、有效模型与 Key 并授权，然后测试场景准备。不要把 Key 发到聊天。若在自己的电脑运行，则按自己的网络条件接入，不依赖本云环境的网络草稿。

## 现有限制与下一阶段

- Key 是单进程临时连接，不是生产级凭据保险库；多实例/长期保存需要后续明确设计。只限制调用/Token 数，不声称金额封顶。
- 候选模型名称与服务可用性需实际权限验证；当前没有任意服务商自定义 URL 功能。
- 原句证据和 Schema 校验降低编造/越权风险，不是自然语言语义准确率保证；真实模型评估与用户测试仍待后续。
- 秒哒、公开部署、跨站 Cookie、赛事规则均未验证；本轮不扩大这些范围。
