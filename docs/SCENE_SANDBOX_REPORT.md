# 场景改版第一批实施报告

日期：2026-10-26。版本：0.5.0。范围依据：[改版方案](SCENE_SANDBOX_REDESIGN.md)第一交付。

## 已完成

- 普通导航移除模型接入；默认服务可用时自定义想法自动整理，无服务时明确提示并可手动／演示体验。兼容接口和组件源码保留。
- 准备页条件摘要与折叠表单，确认前检查必需条件，无需理解模型或填写Key。
- 易损耗零售二维摊位，价签、备货箱、条件告示牌可操作；支持手机、键盘等价入口和减少动态效果。
- 确认三段均分演示需求后，初始成本只记一次，每阶段推进售出、库存、收入和台账；可手动、自动／暂停、直接计算至完整结算、刷新恢复。
- 回到筹备修改新建方案并从头独立推演，原方案保留，可对比。营业中调价、补货、天气不在本批范围。
- 过程表与Agent checkpoint分离；步骤有ORM及PostgreSQL／SQLite不可变保护。修订检查、行锁和条件更新、事务与幂等防止重复结算。
- 过程终态与旧公式对账：30份／12份需求为-117元，15份／同需求为-64.50元。原三类公式和规范fixtures未改；开发库升级0003，未清库。
- 默认服务增加单进程共享尝试额度和输入长度控制，状态接口不披露密钥或模型详情。本轮未调用真实模型。

新增 backend/app/{schemas,simulation,services}/process.py、api/process_routes.py、0003迁移、过程测试，以及 frontend/src/scene/SceneStage.tsx 与 scene.css。
